# Couleurs & Dual Theme

Le Design System Edwyn propose une architecture **Dual Theme** native : le thème **Dark Slate** officiel (utilisé en production sur [edwyn.tech](https://www.edwyn.tech)) et le nouveau thème **Light Mode**, tous deux conçus pour respecter les ratios d'accessibilité WCAG 2.1 AA et APCA.

---

## 🟠 Orange Signature (Brand Accent Universel)

L'orange signature est la constante visuelle d'Edwyn à travers tous les thèmes. Il symbolise le dynamisme, l'authenticité et la transparence de l'ESN alternative. Il est réservé aux actions prioritaires, aux curseurs de simulation, aux CTA et aux indicateurs clés.

## 💻 Activation du Thème en Production

Le basculement dynamique du thème s'effectue via l'attribut standard HTML `data-theme` ou la classe CSS `.theme-light` :

```html
<!-- Activation globale via le document root -->
<html lang="fr" data-theme="light">
  <body>
    <!-- Tous les composants s'adaptent instantanément -->
    <edwyn-button variant="secondary">Mon Bouton</edwyn-button>
    <edwyn-slider label="TJM" .value="650"></edwyn-slider>
  </body>
</html>

<!-- Ou isolation locale sur un conteneur spécifique -->
<div class="theme-light">
  <edwyn-card>
    <h3 slot="title">Carte Thème Clair</h3>
  </edwyn-card>
</div>
```

> 💡 **Bascule Storybook** : Utilisez l'icône de thème (Soleil / Lune) dans la barre d'outils en haut de Storybook pour permuter instantanément l'ensemble des composants entre le Dark Slate et le Light Theme !
