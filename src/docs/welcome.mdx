## 🎯 Notre Vision : L'ESN Alternative

Edwyn est née d'une conviction profonde : le modèle traditionnel des ESN doit être repensé. Notre modèle repose sur trois piliers indissociables :

1. **Transparence Absolue** : Aucun intermédiaire opaque ni marge cachée. Le consultant connaît exactement son TJM et le modèle de redistribution.
2. **Redistribution Équitable** : 100% de la marge excédentaire générée est redistribuée sous forme de prime de performance transparente.
3. **Excellence Technique (Craftsmanship)** : TDD, DDD, Clean Architecture, pair programming et veille technologique active sont au cœur de nos pratiques quotidiennes.

Ce Design System incarne fidèlement ces valeurs :

- **Transparence du code** : 100% open standards, typage strict TypeScript, documentation exhaustive générée depuis le Custom Elements Manifest (CEM).
- **Sobriété et Performance** : Aucun runtime lourd superflu, un bundle ultra-léger (< 13 kB gzippé), aucun vendor-lock-in.
- **Thématisation & Flexibilité** : Support complet du Dark Slate officiel (identique au site public) et du Light Mode via CSS Custom Properties.
- **Accessibilité Universelle** : Conformité WCAG 2.1 AA et APCA intégrée dès la conception.
